# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, critique ideas and code, not people, and assume good faith. Harassment, personal attacks, and discriminatory language are not tolerated.

## Reporting

Report unacceptable behavior to the maintainer at **ai.cyberwar.rts.game@gmail.com**. Reports are kept confidential.
